# MexWebAPI - Hotel / Travel Backend API

ASP.NET Core Web API solution used as a backend for hotel and travel-related platform services.

## Overview
Exposes business APIs consumed by web frontends and admin tools as part of a hotel/travel ecosystem (bookings, property services, and operational integrations).

## Key Features
- REST API endpoints for platform services
- .NET Core service architecture
- Configurable SQL Server connectivity
- Ready for local IIS / Kestrel development

## Tech Stack
- **Framework:** ASP.NET Core / C#
- **Solution:** `MexCoreWebAPI.sln`
- **Database:** Microsoft SQL Server (environment-specific)

## Getting Started
1. Open the solution file
2. Configure app settings for your database
3. Restore and build
4. Run the API project and test endpoints
